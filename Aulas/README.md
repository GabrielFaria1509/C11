# 📊 C11 - Análise de Dados com Python

Bem-vindo à pasta da disciplina **C11 (Análise de Dados com Python)**. 

Este diretório armazena os materiais, anotações de aula e exercícios práticos desenvolvidos ao longo do curso. Todo o conteúdo prático está estruturado em notebooks interativos.

## 🛠️ Sobre o Ambiente
- **Linguagem:** Python 3
- **Formato dos arquivos:** Jupyter Notebook (`.ipynb`)
- **Principais Bibliotecas:** Pandas, NumPy, Matplotlib, Seaborn

## 🚀 Como executar os arquivos

Para visualizar e rodar os códigos presentes nos arquivos `.ipynb`, você pode utilizar uma das seguintes ferramentas:

1. **Visual Studio Code:** Basta ter as extensões do Python e do Jupyter instaladas.
2. **Jupyter Notebook / JupyterLab:** Executando o ambiente localmente via terminal (ex: `jupyter notebook`).
3. **Google Colab:** Caso prefira rodar na nuvem, basta fazer o upload do notebook no [Colab](https://colab.research.google.com/) e executar pelo próprio navegador.
