# 📝 C11 - Atividades e Exercícios Práticos

Este diretório é dedicado à resolução de listas, trabalhos e exercícios práticos da disciplina **C11 (Análise de Dados com Python)**, do curso de Engenharia de Software do Inatel.

O objetivo desta pasta é concentrar toda a aplicação prática dos conceitos de manipulação, limpeza e visualização de dados vistos em aula.

## 📂 Estrutura dos Arquivos

As atividades desenvolvidas aqui utilizam dois formatos complementares:
- **Scripts (`.py`):** Arquivos contendo lógicas mais estruturadas, funções auxiliares, automações ou códigos de execução direta no terminal.
- **Jupyter Notebooks (`.ipynb`):** Utilizados para análises passo a passo, exploração de dados (EDA) e exercícios que exigem visualização imediata de gráficos e tabelas.

## 🚀 Como executar os códigos

### Arquivos `.py` (Scripts)
