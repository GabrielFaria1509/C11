# 🗄️ C11 - Datasets e Bases de Dados

Este diretório é o repositório central para todos os conjuntos de dados utilizados nas aulas e atividades da disciplina **C11 (Análise de Dados com Python)**.

Aqui ficam armazenados os dados em seu estado bruto original e também as versões já limpas e processadas que alimentam os scripts e notebooks de análise.

## 📂 Formatos Comuns
Os arquivos armazenados nesta pasta geralmente incluem:
- **`.csv` / `.tsv`:** Tabelas com dados separados por vírgula ou tabulação (os mais comuns para uso com a biblioteca Pandas).
- **`.xlsx`:** Planilhas estruturadas.
- **`.json`:** Dados em formato de dicionário, frequentemente obtidos via consumo de APIs ou extrações da web.

## ⚠️ Boas Práticas e Organização
- **Mantenha os dados brutos seguros:** Evite sobrescrever o arquivo original baixado. Sempre salve os dados limpos e manipulados em um arquivo novo (ex: `dados_originais.csv` e `dados_processados.csv`).
- **Controle de Versão (Git):** Se estiver usando Git, lembre-se de que arquivos muito grandes (acima de 50MB ou 100MB) podem causar problemas no GitHub. Adicione arquivos muito pesados ao seu `.gitignore` e deixe apenas uma amostra ou um link para o download original no README principal.
